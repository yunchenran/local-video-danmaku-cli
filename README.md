# Local Video Danmaku CLI

本地视频弹幕匹配与 XML 导出工具，计划使用 Python CLI 接入弹弹play开放弹幕网络。

## 当前状态

项目处于设计与接口验证阶段，CLI 代码尚未实现，暂无可下载或运行版本。

应用接入正在申请；逐来源 URL 映射、页面标题及来源筛选能力尚待使用有效凭据验证。本仓库当前仅包含项目说明，不代表功能已经实现或验证。

## 计划功能

- 输入一个本地视频文件，通过文件名、前 16 MiB 数据的 MD5、文件大小及可获取的视频时长匹配作品与剧集。
- 展示候选编号，由用户选择对应剧集。
- 在接口提供真实关联信息的前提下，展示弹幕来源平台、原始视频 URL 和标题，支持选择一个或多个来源；空输入默认全选。
- 将所选弹幕导出为同目录、同文件名主体的 XML，例如 `episode.mkv` → `episode.xml`。
- 为接口请求、候选选择和导出保留必要日志；凭据不写入代码或日志。

## 接入方式

数据来源：弹弹play开放弹幕网络。

参考[官方文档](https://doc.dandanplay.com/open/) 与[接口变更日志](https://doc.dandanplay.com/open/changelog.html) 。

仅按用户对单个视频的实际操作调用接口，用于个人开发学习与测试，不进行批量抓取或商业运营。
